## ✨ Key Features

* **🤖 AI-Driven Generation:** Transform text prompts into fully functional React component code and layouts instantly.
* **🔒 Secure Authentication:** Complete User Registration and Login system implemented using **JWT (JSON Web Tokens)** stored securely via HttpOnly cookies with cross-origin support.
* **📂 Project Management Dashboard:** Users can create, save, manage, and view their generated projects in real-time.
* **⚡ Live Code & Preview Sandbox:** Built-in code preview and error management to render components safely.
* **🌐 Production Deployed:** Hosted live on Render with robust environment configurations and CORS security.

---

## 🛠️ Tech Stack

### **Frontend:**
* **React.js / Vite** (Fast component rendering and build bundling)
* **Tailwind CSS / Modern CSS** (For responsive, sleek UI layouts)
* **Axios** (For seamless REST API integration with the backend)

### **Backend:**
* **Node.js & Express.js** (RESTful API architecture)
* **MongoDB & Mongoose** (NoSQL database for user data and project states)
* **JWT & Cookie-Parser** (Secure session and authentication handling)
